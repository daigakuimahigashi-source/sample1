# AI役員会の使い方ガイド 〜大学社長のための完全マニュアル〜

## はじめに

大学社長、このマニュアルは「AI役員会」の使い方を一から説明するもんやで。
難しいことは何もないから、安心してついてきてな！

---

## 1. AI役員会ってなんやねん？

「AI役員会」っちゅうんは、Claude Code の中に **6人のAI役員** を配置して、
大学社長の経営判断をサポートする仕組みやねん。

たとえば「新メニュー出したいんやけど」って聞いたら、
マーケティングの人、財務の人、法務の人...それぞれの専門家が意見を言ってくれるんよ。

### メンバー紹介

| 役職 | 名前 | ひとこと |
|------|------|---------|
| CTO（技術担当） | 堅実 誠（かたみ まこと） | 「ROI出ますか？」が口癖の技術屋さん |
| CFO（財務担当） | 鬼頭 厳（きとう げん） | お金のことには超厳しい！でも正しいこと言うてる |
| 総務 | 世話田 和子（せわた かずこ） | 何でも丁寧に教えてくれる、チームのお母さん的存在 |
| CMO（マーケ担当） | 華山 創（はなやま そう） | アイデアマン！お客さん目線の提案が得意 |
| マネジメント | 現場 鉄男（げんば てつお） | 「現場で誰がやるん？」が口癖の現場主義者 |
| 法務 | 石橋 慎一（いしばし しんいち） | 「石橋を叩いて渡る」慎重派。法律のプロ |

> **ポイント**: 鬼頭CFOと石橋法務は **わざと厳しく** 設定してあるんよ。
> イエスマンばっかりやったら意味ないからな。厳しい意見こそ大事やで！

## 2. 使い始め方

### ステップ1: Claude Code を起動する

ターミナル（黒い画面）を開いて、こう打つだけやで：

```
claude
```

これだけ！Claude Code が起動して、AI役員会が使える状態になるんよ。

### ステップ2: コマンドを使う

Claude Code の中で **スラッシュ（/）** から始まるコマンドを打つと、
各役員に相談できるんや。

---

## 3. よく使うコマンド

### 会議を開く — `/meeting`

全員で会議するときに使うんや。一番よく使うコマンドやで。

```
/meeting 新メニューの価格設定について
```

こうすると、6人の役員が順番に意見を言って、
最後にCOO（秘書）がまとめてくれるんよ。

**会議の流れ:**
1. COO（秘書）が議題を整理
2. 華山CMO → 堅実CTO → 現場マネジメント → 鬼頭CFO → 石橋法務 → 世話田総務 の順で発言
3. COOが全員の意見をまとめて、アクションプラン（やることリスト）を作る
4. 議事録が自動で保存される

### 個別に相談する

「全員じゃなくて、一人だけに聞きたい」ってときは、個別コマンドを使うんや。

```
/cfo 来月の資金繰りについて相談したい
```

```
/cmo SNSで集客する方法を教えて
```

```
/soumu スタッフの書類整理を手伝って
```

### ファイルを整理してもらう — `/seiri`

「パソコンの中がごちゃごちゃで...」ってとき、世話田さんが整理してくれるで。

```
/seiri このフォルダの中を整理して
```

世話田さんが今の状態を見せてくれて、「こう整理しましょか？」って提案してくれる。
勝手にやったりせぇへんから、安心してな。

| 打つコマンド | なにが起こる | 使う場面 |

| `/cto 相談内容` | 堅実CTOに相談 | システムやIT関連のこと |

## 5. 使い方のコツ

### コツ1: 具体的に聞くと、具体的に返ってくる

```
× /meeting メニューどうしよう
○ /meeting 牛タンの原価が上がってきたので、価格改定か代替メニューを検討したい
```

### コツ2: 数字があると鬼頭CFOが喜ぶ

```
× /cfo 広告出したい
○ /cfo Instagram広告に月5万円かけて集客したい。現在の月間来客数は約2000人
```

### コツ3: 一つの議題に一つの会議

あれもこれも一度に聞くと、話が散らかるんよ。
大きなテーマは分けて会議しような。

### コツ4: 議事録を活用する

会議のたびに `ai-board/minutes/` フォルダに議事録が保存されるで。
「あの時なんて決めたっけ？」ってなったら見返してな。

---

## 6. 困ったときは

### 「コマンドが効かへん！」
→ スラッシュ（/）から始まってるか確認してな。`/meeting` やで、`meeting` だけやとあかんで。

### 「役員の意見が全部同じやん」
→ もう一回 `/meeting` で聞いてみてな。議題をもっと具体的にすると、意見が割れやすくなるで。

### 「世話田さんに整理してもらったけど、よくわからん」
→ 「もっとかみ砕いて教えて」って言うてみてな。世話田さんは何回でも丁寧に説明してくれるで。

### 「とりあえず何から始めたらええん？」
→ まずはこれを試してみ：
```
/meeting 焼肉ここからの今月の課題と優先事項を整理したい
```

```
焼肉ここから/
├── CLAUDE.md              ← AI役員会の設定ファイル（触らんでOK）
├── ai-board/              ← AI役員会のフォルダ
│   ├── personas/          ← 各役員の性格が書いてある（触らんでOK）
│   ├── templates/         ← 会議の型紙
│   └── minutes/           ← 議事録がここに貯まっていくで
├── intranet/              ← 売上ダッシュボード
├── manual/                ← このマニュアルが入ってる
│   ├── 使い方ガイド.md     ← 今読んでるやつ
│   └── コマンド一覧.md     ← コマンドの一覧表
├── Code.gs                ← PDF自動リネームシステム
└── その他のファイル...
```

> 「触らんでOK」って書いてあるファイルは、そのままにしといてくださいね。
> 大学社長が見るのは `minutes/`（議事録）と `manual/`（マニュアル）だけで大丈夫ですよ！
