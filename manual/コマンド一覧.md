# AI役員会 コマンド一覧（クイックリファレンス）

## 全員で会議

| コマンド | `/meeting 議題` |
|---------|----------------|
| 説明 | 6人の役員全員で議題について議論する |
| 例 | `/meeting 新店舗の出店場所を検討したい` |
| 例 | `/meeting 原価率が上がってきている問題について` |
| 例 | `/meeting 夏のキャンペーン企画を考えたい` |

---

## 個別相談

### 堅実CTO（技術のこと）
| コマンド | `/cto 相談内容` |
|---------|----------------|
| 得意分野 | IT・システム・POSレジ・ダッシュボード |
| 例 | `/cto タブレット注文を導入すべきか` |
| 例 | `/cto スマレジの使い方で困っていること` |

### 鬼頭CFO（お金のこと）
| コマンド | `/cfo 相談内容` |
|---------|----------------|
| 得意分野 | 予算・コスト・投資判断・F率L率 |
| 例 | `/cfo 来月の資金繰りが心配` |
| 例 | `/cfo 内装リニューアルに500万円かける価値はあるか` |

### 世話田総務（手続き・整理のこと）
| コマンド | `/soumu 相談内容` |
|---------|----------------|
| 得意分野 | 書類整理・手続き・社内の仕組みづくり |
| 例 | `/soumu 新しいスタッフの入社手続きリストを作って` |
| 例 | `/soumu 月次報告のテンプレートを作って` |

### 華山CMO（集客・宣伝のこと）
| コマンド | `/cmo 相談内容` |
|---------|----------------|
| 得意分野 | SNS・キャンペーン・メニュー戦略・ブランディング |
| 例 | `/cmo Instagram での投稿ネタを考えて` |
| 例 | `/cmo 観光客向けの集客プランを提案して` |

### 現場マネジメント（スタッフ・店舗運営のこと）
| コマンド | `/management 相談内容` |
|---------|----------------|
| 得意分野 | シフト管理・研修・サービス品質・36協定 |
| 例 | `/management 繁忙期のシフトの組み方` |
| 例 | `/management 新人スタッフの研修プランを作って` |

### 石橋法務（法律・リスクのこと）
| コマンド | `/compliance 相談内容` |
|---------|----------------|
| 得意分野 | 労働法・食品衛生法・景表法・契約 |
| 例 | `/compliance 深夜営業の届出は必要か` |
| 例 | `/compliance メニューに「国産牛」と書いて大丈夫か` |

## ファイル整理

| コマンド | `/seiri 整理したい内容` |
|---------|----------------------|
| 説明 | 世話田総務がファイル整理を手伝ってくれる |
| 例 | `/seiri このフォルダを整理して` |
| 例 | `/seiri 請求書ファイルの名前の付け方を教えて` |

---

## 使い方のポイント

1. **スラッシュ（/）を忘れずに** — `/meeting` であって `meeting` ではない
2. **議題は具体的に** — 「どうしよう」より「○○を△△したい」
3. **数字があるとベター** — 特にCFOに聞くときは金額や期間を添えると◎
