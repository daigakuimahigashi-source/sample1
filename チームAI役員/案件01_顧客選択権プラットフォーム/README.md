# 案件01：顧客選択権プラットフォーム

## 概要
「顧客が自らの意思で担当者を選べる仕組み」を、電子署名・電子依頼書で実現するビジネスアイデア。

## 背景
- 生命保険業界では、担当者が退職・独立しても顧客情報は「会社の資産」として扱われる
- しかし顧客本人が「この人に相談したい」と思う権利は保護されていない
- 将来的には保険以外（税理士・士業・コンサル・美容師等）にも展開可能
